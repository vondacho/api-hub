This is the documentation for the API contract lifecycle platform: how a contract
gets onboarded, the design guidelines it is scored against, and how to find and
consume what has been registered.

## Where to start

- **[Onboarding](/doc/onboarding/)** — submit a contract for parsing, validation and scoring.
- **[Design guidelines](/doc/design-guidelines/)** — the rules a contract is graded against, and why.
- **[Catalog](/doc/catalog/)** — find a registered API and read its contract.
- **Usage** — [integrate](/doc/usage/integration/), [mock](/doc/usage/mocking/), or reach an API over [MCP](/doc/usage/mcp/).
